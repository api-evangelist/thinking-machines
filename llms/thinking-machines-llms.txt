# Thinking Machines Lab

> Thinking Machines Lab is an AI research and product company building tools to make
> AI systems more widely understood, customizable, and generally capable. Its
> flagship developer product is Tinker, a managed API and Python SDK for
> fine-tuning and sampling open-weight language models (SFT, RL, distillation),
> plus Inkling, an open-weights model.

This llms.txt was generated by the API Evangelist enrichment pipeline from the
provider's public site and Tinker documentation (no provider-published llms.txt
was found).

## Products

- [Tinker](https://thinkingmachines.ai/tinker): Managed training/fine-tuning + sampling API with a Python SDK and CLI.
- [Inkling](https://thinkingmachines.ai/inkling/): Open-weights model.
- [Tinker Console](https://tinker.thinkingmachines.ai/): Web console; issues API keys; includes a Playground.
